Welcome to Cloud Computing

Cloud computing provides computing resources such as storage, servers, databases and software over the Internet.

Cloud Services

IaaS

Infrastructure as a Service provides virtual servers, storage and networking resources.

PaaS

Platform as a Service provides a platform for developing and deploying applications.

SaaS

Software as a Service provides software applications through the Internet.

Cloud Deployment Models

Public Cloud

Cloud resources are provided to many users over the Internet.

Private Cloud

Cloud infrastructure is dedicated to a single organization.

Hybrid Cloud

Combination of public and private cloud environments.

Advantages

  • Cost saving
  • Easy access from anywhere
  • Scalability
  • Data backup
  • High availability
